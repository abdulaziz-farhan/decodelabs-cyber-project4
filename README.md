# decodelabs-cyber-project4
The System Vulnerability Checklist is a Python-based cybersecurity project designed to assess the security configuration of a Windows computer. It helps users identify weaknesses and understand how to improve system security. The project uses Python and PowerShell commands to examine areas including Windows Firewall status, Microsoft Defender protection, BitLocker disk encryption, and administrator and guest accounts. After the audit script runs, it presents results and saves evidence in report files, where supported by the implementation. Findings can be reviewed as passed checks, warnings, or items requiring manual verification. The project also provides guidance for reviewing Windows updates, application versions, password practices, multi-factor authentication, and screen-lock settings. These checks demonstrate the importance of updating software, limiting unnecessary account privileges, enabling protections, and following safe computer-use practices. To use the project, users need a Windows 10 or Windows 11 computer, Python, and PowerShell. They can clone the GitHub repository, open it in Visual Studio Code, and run the audit script from the terminal. This project is intended for educational and defensive purposes. It does not perform penetration testing, exploit vulnerabilities, collect passwords, or automatically change system settings. Its purpose is to support a security review and introduce users to system vulnerability assessment.
